# ÷ Calcolatore di proporzioni online
### Strumento di calcolo matematico semplice ed effervescente.
Inserisci i valori e calcola la tua proporzione con la formula `a:b=c:d`, come per esempio `4:3=100:X` ⇒ `X=(3×100)/4`.
